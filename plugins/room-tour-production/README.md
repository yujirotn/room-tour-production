# 住宅ルームツアー

Codexの制作スキルとローカル生成処理を同梱したプラグインです。

入口は [SKILL.md](skills/room-tour-production/SKILL.md)。Node.js22以降、Blender5.1系を使用します。runtimeで`npm ci --ignore-scripts`、`npm test`、`npm run demo`を実行すると架空住宅のモデルと歩行HTMLを生成できます。顧客図面・メーカー部品は同梱していません。

# 案件ごとの検品

## 図面と形状

- 尺度・寸法連鎖、壁厚、各室、建具・窓の位置/幅/高さ、階段・床穴、設備を原図と比較。
- 仮設定した床高さ・階高・天井高・内装・開閉方向を記録。確認値と参考値を分ける。
- 原図にない屋根・敷地・外構を追加していないか確認。
- BlenderとGLBとHTMLの3成果物が別々に存在し、最新版の入力に一致する。

## 高品質な描画

- 木目とタイルのスケール、UVの向きと継ぎ目、粗さ・金属・ガラスが最終HTMLで適切。
- 巾木、建具枠、金具、面取り、階段の踏板と手摺。開口を壁が塞がない。
- 白飛び/黒潰れ、光漏れ、ガラス透過、影、床重なり、天井の欠落を室内と全体で確認。
- 外部素材の許諾がない場合は独自の汎用設備を用いる。メーカー素材が必要なら対応素材を正当な利用範囲で別途用意する。

## 歩行と建具

- 全部屋のボタンから安全に開始。WASD、矢印、ドラッグ、Esc、階切替を実操作。
- 壁/床境界/設備/閉じた戸で止まり、開いた戸を通行できる。
- 全開き戸・引戸を開く/閉じる。固定枠と金具を含む葉の動き、途中の衝突、人がいる位置への閉鎖停止。
- Eキー、建具クリック、一覧操作を実操作。ガラス・金具が別meshでも葉と一緒に動く。
- 階段を上下に連続移動し、上階床の穴と頭上空間、階切替を確認。
- 最終画面のスクリーンショットと操作記録を案件フォルダに保存。公開リポジトリに顧客QAを入れない。

自動検証で分かるのは入力とモデル構造・衝突/動作の一部。意匠品質、原図再現、使いやすさは実画面で確認する。未検証事項は納品時に明示し、推測で「完成」「正確」「高品質」を主張しない。
